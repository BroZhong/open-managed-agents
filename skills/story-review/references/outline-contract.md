# 大纲提交规范

这个契约同时服务于故事架构师和金牌编辑，是结构与质量标准的入口。`章节大纲.md` 必须按本文件格式写成可提交稿；不符合格式要求的大纲应退回修改。

细则分文件：

- craft 细则（开篇技巧、钩子标准、反套路、反 AI 腔）见 `craft-checklist.md`。
- 连续性细则（30 章 5 维状态追踪与一致性检查）见 `continuity-tracker.md`。

## 总体结构

`章节大纲.md` 由以下四部分组成，每个部分均为必填：

1. 故事基础信息
2. 角色表
3. 付费点
4. 分章大纲

建议使用以下标题：

```text
# 大纲提交稿

## 一、故事基础信息
## 二、角色表
## 三、付费点
## 四、分章大纲
```

## 一、故事基础信息

必填字段：

```text
题材类型：
背景设定：
核心卖点：
```

字段要求：

- `题材类型`：1-3 个关键词，例如“豪门复仇、甜宠、悬疑”。
- `背景设定`：故事发生的时代、地点、社会环境，1-3 句。
- `核心卖点`：一句话概括最吸引读者的核心冲突或悬念。

## 二、角色表

列出所有主要角色：主角、主要配角、核心反派。每个角色包含以下信息：

```text
姓名：
身份：
性格特征：
核心动机：
关键关系：
```

字段要求：

- `姓名`：角色全名。
- `身份`：社会身份、职业或头衔。
- `性格特征`：2-3 句概括核心性格。
- `核心动机`：这个角色追求什么、害怕什么。
- `关键关系`：与其他角色的关系。

多名角色可重复这一组字段。

## 三、付费点

明确标注免费章节范围和付费起始点：

```text
免费章节：第1章 - 第5章
付费起始：第6章
```

要求：

- `免费章节` 必须机器可读，格式为 `第1章 - 第X章`、`第1章-第X章` 或等价写法。
- `付费起始` 必须是免费章节后一章。
- 免费部分最后一章必须以强悬念或重大反转结尾，让读者产生继续付费阅读的冲动。

## 四、分章大纲

结构要求（硬性，不随题材变）：

- 正好 30 章。
- 第 1-5 章为开篇段。
- 第 30 章关闭主外部冲突和主情感弧。

节奏建议（偏向快节奏/强钩子类型；文学向、慢热向可按故事实际调整力度，但开篇段仍要建立核心张力）：

- 第 5 章结尾通常是开篇段最强转折或重大危机。
- 第 6 章承接第 5 章后果，并推进新的行动目标。
- 第 1-3 章应尤其抓人且易懂。
- 后 20%（末 6 章，第 25-30 章）使用更不可逆、更有情感代价的选择。

每一章按以下格式填写：

```text
第X章：章节标题

- 视角人物：
- 场景目标：
- 核心冲突：
- 章末钩子：
- 关键揭示：
- 章节高潮：
- 对白重点：
```

字段说明：

| 字段 | 作用 | 写法要点 |
| --- | --- | --- |
| 视角人物 | 确定叙事视角 | 填角色名，一章一个主视角 |
| 场景目标 | 这章存在的意义 | 1-2 句，说清楚这章推进了什么 |
| 核心冲突 | 驱动情节的矛盾 | 1-3 句，写出对立双方和张力 |
| 章末钩子 | 留住读者的理由 | 1-2 句，必须制造继续读下一章的冲动 |
| 关键揭示 | 新信息或反转 | 1-2 句，这章让读者知道了什么新东西 |
| 章节高潮 | 情绪最强的一刻 | 1-2 句，全章最有冲击力的瞬间 |
| 对白重点 | 对话方向指引 | 1-2 句，核心对白的情绪基调和内容方向 |

章节头支持「第 X 章：标题」，也支持 `# 第 X 章：标题` / `## 第 X 章：标题` 等 Markdown 标题；字段名支持 `- 字段名：`，也支持 `- **字段名：**`；正文里可以使用 `**` 加粗。仍不要出现 ` ``` ` 代码块、整行只有 `---` 的横线，也不要出现英文元话术串（`let me` / `I will` / `as an AI` / `I can't` / `I cannot` / `here's my approach`）。这些会让 `story-seed validate` 判整篇不通过。章节标题不要留空。

## 质量规则

- 每章必须有至少一个不可删除的核心事件（文学向作品的安静/喘息章也要承担推进作用，不空转）。
- 每章必须有真实冲突或推进，不只是聊天、过渡或复述。
- 每章结尾必须有有效钩子。
- 免费末章的钩子必须特别强，这是读者是否付费的关键瞬间。
- 每章开头 20% 应该有动作或可指认的张力：危机、发现、异常情况、冲击台词、背叛、重大选择、倒计时压力，或文学/慢热向里已具体落地的情绪暗流。
- 默认规避天气、醒来、日常、前情回顾、平铺直叙问候和长 exposition 开头；文学/慢热向可作为例外，但前 20% 仍须埋下具体张力或疑问，细则见 `craft-checklist.md`。
- 不要重复同一 plot module，要升级到下一层后果。
- 保持严格时间线和关键物品/证据状态。
- 避免假悬念：只有信息隐瞒、没有主动后果的钩子不算。
- 付费起始章要兑现免费末章承诺，同时打开新的高价值问题。

上述质量规则的可操作细则见 `craft-checklist.md`；跨章一致性的逐维核对见 `continuity-tracker.md`。

## 评审结论

结论分级的权威定义在金牌编辑 skill（`story-review/SKILL.md`「问题分级规则」），此处为同一套规则的转写，两处必须一致：

- `不通过`：存在提交阻断（validate 结构问题、付费摘要四种阻断、标准文件缺失），或关键问题多到该稿方向性返工。
- `需修改`：无提交阻断，但有关键问题（不修读者会流失或故事不成立的内容硬伤）。
- `通过`：无提交阻断、无关键问题，只剩提醒项。
