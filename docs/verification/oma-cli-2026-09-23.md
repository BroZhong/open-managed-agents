## Reproduction and limits

Run `node cli/scripts/live-acceptance.mjs` only with explicit environment credentials
and authorization to create isolated test resources. It refuses missing connection
configuration and never defaults to a production endpoint.

The live workflow verifies the deployed path; deterministic fixtures inject
otherwise disruptive network, timeout, symlink, overwrite and replay failures.
The repository Host integration verifies the #179 transaction boundary in memory;
it is not a proof of every production PostgreSQL interleaving. Doctor cannot
infer that transaction implementation from OpenAPI. No platform other than the
recorded macOS runtime has been exercised; registry publication remains separate.
